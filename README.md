# Portafolio de Josué González — V2

Sitio estático bilingüe para GitHub Pages, construido con HTML, CSS y JavaScript sin frameworks.

## Estructura

- `index.html`: página principal.
- `case-studies/`: tres casos de estudio independientes.
- `assets/css/styles.css`: estilos globales y responsive.
- `assets/js/main.js`: traducciones, navegación y animaciones.
- `assets/js/dashboard.js`: demo interactiva con datos sintéticos.
- `cv/`: CV descargable en español e inglés, en PDF y DOCX.

## Publicar en GitHub Pages

1. Guarda una copia de seguridad del repositorio actual.
2. Reemplaza el contenido del repositorio `jgonzalez-bi.github.io` con estas carpetas y archivos.
3. Haz commit y push a la rama `main`.
4. GitHub Pages publicará automáticamente los cambios en `https://jgonzalez-bi.github.io/`.

Comandos opcionales:

```bash
git add .
git commit -m "Upgrade portfolio with case studies and downloadable CV"
git push origin main
```

## Antes de publicar

- Confirma que las fechas y cargos del CV siguen vigentes.
- Revisa el correo y enlace de LinkedIn.
- Todos los gráficos del sitio usan datos sintéticos y no contienen información interna.
